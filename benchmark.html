生成器效能測試

自動按 Start，再像 Resume 一樣連續跑完所有階段，比較各版本的記憶體、STL 讀取次數、生成與繪製時間，並檢查 X3D（DEF/USE）匯出內容是否一致。 生成器畫面固定為 1280×800、像素比固定為 1，讓不同電腦的繪製時間可以比較。

第一次使用：準備兩個版本
  1. 在 threejs_geo 資料夾執行 git worktree add ../threejs_geo_before baseline，把修改前的版本放在旁邊的 threejs_geo_before。baseline branch 是共用 geometry 之前的版本，只多了跟新版相同的斗栱重疊修正，讓兩邊的生成結果一致。
  2. 到 threejs_geo 的上一層資料夾執行 python -m http.server 8000。兩個版本要由同一個 server 提供，這個頁面才能讀取它們的畫面。
  3. 用 Chrome 打開 http://localhost:8000/threejs_geo/benchmark.html。

測試時請讓這個分頁保持在前景。瀏覽器會放慢背景分頁的計時器，生成時間會不準。

暫停繪製時，「第一次繪製」等於一次把所有構件上傳到 GPU；不暫停的話，上傳會分散在生成過程中，這個數字會很小。
